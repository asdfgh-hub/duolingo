# Cabin Crew English

Самостоятельное iOS-приложение для изучения английской лексики кабинного экипажа в формате коротких игровых уроков.

## Что есть в MVP
- тематическая карта курса A2–B1;
- 11 тематических блоков и около 110 слов/выражений с русским переводом и контекстными примерами;
- упражнения с выбором перевода и английского выражения;
- озвучка английских слов штатным AVSpeechSynthesizer (по умолчанию en-GB);
- XP, серия занятий, статистика;
- локальное интервальное повторение слов;
- AI-генератор новых уроков через OpenAI-compatible Chat Completions API;
- генерация карточек слов и новых тестовых упражнений за один API-запрос;
- сохранение AI-уроков на iPhone — повторное прохождение не требует API;
- хранение API-ключа в iOS Keychain;
- встроенный курс и уже сохранённые AI-уроки доступны без интернета.

## Подключение генерации заданий через API

1. Открой приложение и нажми значок ✨ на экране курса (или карточку «Создать новые задания с AI»).
2. В разделе «Подключение» нажми «Настроить».
3. Для Router.cheap укажи Base URL `https://router.cheap/v1`, точный ID модели, доступной твоему ключу, и API-ключ.
4. Сохрани настройки. Ключ записывается в Keychain iPhone, а адрес и ID модели — в настройки приложения.
5. Выбери тему, уровень A2/B1/B1+ и размер набора, затем нажми «Сгенерировать урок».

Генератор использует endpoint `/chat/completions` и формат сообщений OpenAI Chat Completions. Подойдут другие провайдеры только при условии совместимости с этим API. Нативный Anthropic Messages API без OpenAI-совместимого шлюза этим MVP не поддерживается. ID модели нужно скопировать из актуального каталога своего провайдера — приложение не предполагает конкретную модель.

Один запрос создаёт словарные карточки и столько же новых тестов с вариантами ответов. Генерация платная по тарифу выбранной модели. После создания урок и задания сохраняются локально, их можно проходить повторно без новых запросов. Не нажимай генерацию повторно, пока предыдущий запрос выполняется.

AI создаёт языковые учебные материалы, а не официальные стандартные фразы или процедуры авиакомпании. Не используй сгенерированный материал как источник инструкций по безопасности, медицинским действиям или действиям экипажа.

## Темы курса
Кабина и оборудование; посадка и багаж; обслуживание; забота о пассажирах; объявления; этапы полёта; командная работа; задержки и сложные ситуации; самочувствие и первая помощь (лексика); термины безопасности; профессия и собеседование.

## Важное ограничение
Приложение обучает английским словам и примерам речи. Это не курс подготовки кабинного экипажа, не руководство по безопасности и не замена утверждённым процедурам авиакомпании. Реальные инструкции, фразеология и обязанности могут отличаться в зависимости от оператора и типа воздушного судна.

## Сборка через GitHub Actions
1. Создай отдельный GitHub-репозиторий, например `cabin-crew-english`.
2. Загрузи содержимое этой папки в корень репозитория (не загружай сам zip внутрь репозитория).
3. Открой вкладку Actions и разреши запуск workflow, если GitHub попросит.
4. Запусти workflow `Build Cabin Crew English IPA` вручную.
5. После завершения скачай artifact `CabinCrewEnglish-unsigned-IPA`.

Проект рассчитан на Xcode 16+, iOS 16+. IPA unsigned; для установки потребуется Sideloadly/AltStore или другая подходящая подпись.
